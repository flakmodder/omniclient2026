# OmniClient 2026
===============

free hacked client for minecraft java. i got tired of paid clients so i
made my own and figured other people might want it too.

# features
--------
- x-ray (see ores and caves through walls)
- killaura (auto attack, configurable range)
- fly + jesus (walk on water)
- esp + tracers
- antiknockback
- 200 cheats
- thousands of custom skins
- skin customizer

# install
-------
1. run OmniClient-Setup.exe
2. click through the installer (needs admin, it fixes your java and
   launcher paths so it works with every launcher, thats normal)
3. start the game, the menu opens with right shift

works with the vanilla launcher, tlauncher, prism, and curseforge /
modrinth app packs. win 10/11 64bit, java 8 to 21.

# notes
-----
- if your antivirus complains its a false positive. cheat clients use
  the same memory tricks as malware so heuristics freak out sometimes.
  scan it yourself if you want, its clean
- no config, no setup. works on most servers unless they run strict
  anticheats
- close the game before installing
